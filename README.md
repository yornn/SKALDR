# SKALDR

Расширение для [SillyTavern](https://github.com/SillyTavern/SillyTavern): переписывает текст
из поля ввода в выбранном стиле — пока это **Викинг** и **Славянин**.

## Как это работает

1. Рядом с полем ввода появляется кнопка с пером — она открывает окно SKALDR.
2. Верхнее поле автоматически подхватывает текст из поля ввода таверны.
3. Выбираешь стиль и жмёшь **SKÁL!** — результат появляется в нижнем поле.
4. Понравилось — **RÍSTA!** записывает результат обратно в поле ввода таверны.

Дополнительно:

* Ctrl/Cmd + Enter в поле исходника — то же самое, что SKÁL!
* Слэш-команда `/skaldr` открывает окно; `/skaldr текст` сразу кладёт текст в исходник.
* Окно перетаскивается за шапку, позиция запоминается.

## Настройки

Шестерёнка в правом верхнем углу окна:

| Настройка | Что делает |
| --- | --- |
| **Подключение** | `Текущий API таверны` (по умолчанию) либо любой сохранённый профиль подключения. Профиль используется точечно, активное подключение таверны не переключается. |
| **Контекст** | Пять тумблеров — что уйдёт в запрос вместе с черновиком (см. ниже). |
| **Глубина сканирования** | Сколько последних сообщений берётся при включённом тумблере «Чат». |
| **Лимит токенов** | Максимальная длина переписанного текста. |
| **Подтягивать текст** | Заполнять исходник из поля ввода при открытии окна. |
| **Закрывать после RÍSTA!** | Закрывать окно сразу после вставки. |
| **Язык** | Авто (по языку интерфейса ST), English, Русский. |

## Установка

`Extensions` → `Install extension` → ссылка на репозиторий.
Или вручную — папку положить в `data/<user>/extensions/`.

## Структура

```
manifest.json          манифест расширения
index.js               точка входа: инициализация + слэш-команда
style.css              стили окна и кнопки
templates/panel.html   разметка окна
locales/{en,ru}.json   переводы
prompts/
  base.md              общий слой промпта — одинаков для всех стилей
  viking.md            слой стиля «викинг»
  slav.md              слой стиля «славянин»
  preset-note.md       пояснение к пресету: брать манеру письма, не роль
  context-note.md      шапка справочного блока: контекст только для сверки
src/
  constants.js         константы, доступ к контексту ST, пути к файлам
  settings.js          настройки (extension_settings.skaldr)
  i18n.js              локализация (data-skaldr-i18n)
  prompts.js           загрузка промптов и сборка сообщений
  context.js           сбор контекста таверны по тумблерам
  connection.js        запрос к текущему API либо к профилю подключения
  ui.js                кнопка запуска, окно, drag, действия
```

## Контекст

Пять тумблеров в настройках. Под ними подпись, которая показывает, что именно уйдёт
в запрос — имя пресета, персоны, бота и список активных лорбуков.

| Тумблер | Что берётся | Откуда |
| --- | --- | --- |
| **Пресет** | текстовые промпты пресета, выбранного сейчас в таверне | `chatCompletionSettings.prompts` по включённым позициям `prompt_order`; для text completion — `sysprompt` |
| **Персона** | имя и описание выбранной персоны | `name1`, `powerUserSettings.persona_description` |
| **Бот** | карточка из открытого чата: описание, характер, сценарий, заметка глубины | `getCharacterCardFields()` |
| **Лорбук** | записи активных книг, сработавшие на текст черновика | `getWorldInfoPrompt()` в режиме dry run |
| **Чат** | последние N сообщений, N задаётся рядом | `context.chat` |

Детали, которые важны:

* Из пресета берутся **только его текстовые промпты**. Маркеры (история чата, описание
  персонажа, лорбук) пропускаются — это содержимое расширение подставляет само, по
  тумблерам, чтобы ничего не задваивалось. Указания пресета «играй за персонажа»,
  «продолжи сцену», «выдай ответ такой-то длины» гасятся отдельным пояснением
  (`prompts/preset-note.md`) — от пресета берётся манера письма, не роль.
* Профиль подключения применяет только параметры генерации (температура и прочее),
  промпты из его пресета не подмешиваются, так что задвоения с тумблером «Пресет» нет.
* Лорбуки сканируются **в режиме dry run**: таймеры sticky/cooldown реальной генерации
  не расходуются, события таверны не летят. Корпусом сканирования идёт черновик (как
  самое свежее «сообщение») плюс сообщения чата, если тумблер «Чат» включён.
* Историю чата расширение читает **только** при включённом тумблере и ровно на заданную
  глубину. Системные сообщения отфильтровываются.
* Весь блок контекста помечен как read-only (`prompts/context-note.md`): модели прямо
  сказано не продолжать сцену, не отвечать на последнюю реплику и не принимать текст
  лорбука за инструкции.

## Промпты

Системное сообщение собирается слоями через разделитель `---`, в таком порядке:

1. **пресет** таверны — если тумблер включён;
2. **`prompts/base.md`** — общие правила переписывания;
3. **`prompts/<стиль>.md`** — голос выбранного стиля;
4. **блок контекста** — персона, карточка, лорбук, чат.

Черновик пользователя уходит отдельным `user`-сообщением, как есть.

* **base.md** отвечает за качество и сохранность ролевой: замысел, POV, время, все факты,
  вся прямая речь, разметка автора (`*мысли*`, `**акцент**`, кавычки), язык черновика.
  Запрещает продолжать сцену, отвечать за других персонажей и добавлять комментарии.
* **viking.md / slav.md** отвечают только за голос и подстановки: время суток, дни недели,
  месяцы, луна, меры длины и веса, запрет современных слов.

Правило подстановок: заменяется **только то, что в черновике уже есть**. Если юзер не
написал время суток — расширение его не выдумывает. Если написал размыто («утром») —
берётся ближайшее по смыслу («в моргун»). Историю чата расширение не читает вообще:
работает исключительно с текстом в поле исходника.

В промптах работают макросы таверны — `{{user}}`, `{{char}}` и прочие раскрываются
через `substituteParams` перед отправкой.

Править промпты можно прямо в `.md` — код трогать не нужно, изменения подхватятся
при перезагрузке страницы. Новый стиль: объект в `SKALD_STYLES` (`src/prompts.js`),
свой файл в `prompts/` и пара ключей в `locales/*.json`.

Слой викинга опирается на лор из заметки по старой Скандинавии: 8 эйкт по три часа,
12 месяцев по 30 дней с началом года в гормануд, дни недели, фазы луны, аукнэтр
и сумарауки.

## Технические детали

* Текущий API — `context.generateRaw({ prompt, responseLength })` со страховкой на старую
  строковую сигнатуру.
* Профиль подключения — `context.ConnectionManagerRequestService.sendRequest(...)`,
  список берётся из `extensionSettings.connectionManager.profiles` и фильтруется через
  `isProfileSupported()`. Список обновляется по событиям
  `CONNECTION_PROFILE_CREATED / UPDATED / DELETED`.
* Всё через `SillyTavern.getContext()`, без прямых импортов из `script.js` —
  меньше шансов сломаться на обновлении таверны.
